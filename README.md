# Abhilash GS – Portfolio

Personal portfolio website for **Abhilash GS** – Network Engineer specializing in Cisco Routing, Wireless, Security & Automation.

## How to Host on GitHub Pages (Free)

1. Create a new GitHub repository named:  
   `your-username.github.io`  
   **or**  
   `abhilash-portfolio` (any name is fine)

2. Upload all files from this folder to the repository:
   - `index.html`
   - `css/` folder
   - `js/` folder
   - `assets/` folder (contains your profile photo)

3. Go to **Settings → Pages**
4. Under **Source**, select **Deploy from a branch**
5. Choose branch: `main` and folder: `/ (root)`
6. Click **Save**

Your portfolio will be live at:  
`https://your-username.github.io/`  
or  
`https://your-username.github.io/abhilash-portfolio/`

## Customization Needed

Before publishing, please update these placeholders in `index.html`:

- Email address
- LinkedIn profile URL
- GitHub profile URL

Search for `your.email@example.com`, `yourprofile`, and `yourusername` and replace them with your real details.
